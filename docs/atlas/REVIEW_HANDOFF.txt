   relevant master A-02/C-02/C-03 requirements. Form your own failure hypotheses

   contains exact SHA-256 and Git blob hashes. All source acquisition is offline.
3. Try falsifying the guarantees: missing/duplicate labels, unknown vocabulary,

   instructions, target-review mismatch, ID conflict and concurrent import.

   filesystem operations as separate transactions. Inspect raw output retention
   and rights limitations before proposing any public receipt service.
6. Report each finding with file/line, reproducer, expected/observed behavior,
   evidence, severity, strongest innocent explanation and falsification condition.
   Preserve disagreements. Do not use agreement with another model as an oracle.
