# Paired Citation-Network Correctness Fixture - Revised

These files belong under `tests/cases/`.

The revised pair removes explicit `load-bearing` labels. Each citation instead
contains a prose description of how it is used. The audit must infer whether the
citation performs evidentiary work or merely supplies history, ceremony, or
dismissal.

Signals are crossed:

- healthy case: peripheral, lightly cited dissent but surviving independent
  routes and real narrowing;
- closed case: centrally published dissent cited once, but only ceremonially,
  with hub-dependent evidentiary connectivity and no narrowing.

This prevents a single dissent-presence, venue, or citation-count heuristic from
passing both cases.
